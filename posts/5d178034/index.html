友人帐：同一份友链信息，三种格式

不同主题的友链格式不一样：Butterfly 系吃 YAML，Volantis 系吃 JSON，还有站点只认表格。与其让别人自己猜，不如在友链页顶部做一个分栏，把三种格式都摆出来。

Butterfly 自带 tabs 标签，不需要额外插件。在 [Blogroot]\source\link\index.md 里写：

文件：[Blogroot]/source/link/index.md ｜ 改法：替换正文里已有的 {% tabs link-format %} 整段（没有就插在页面标题下面）；三个标签页里的「站点名称 / yourdomain.com」换成本站信息，标签文字可改。

几个容易踩的点：

  • {% tabs 分组名 %} 里的分组名只是标识，不能重复；<!-- tab 标签文字 --> 与 <!-- endtab --> 必须成对。
  • 用三个反引号围起来的代码块里，标签会原样显示，不会被 Hexo 执行；正文里要原样显示标签时，才需要用 raw 包裹。
  • 表格那一栏别用太长的链接，手机端会横向溢出。截图地址这种长串，直接单独放一行代码块更稳。

文件：[Blogroot]/source/css/twikoo.css ｜ 改法：替换已有的 #twikoo .tk-comments-title 规则（第 45 行附近）；只想改间距就只动 margin-top，字号那两行可以不写。

如果只想让间距生效、不想动字号，单独留 margin-top 即可。改完记得升 twikoo.css 的 ?v= 版本号，否则浏览器会继续用旧缓存。

让新模块跟着「美化设置」换色

前面几节的样式之所以能跟着主题色变，是因为遵守了同一条约定：颜色只从 CSS 变量派生，不写死十六进制。

说明：示意内容，不需要修改。演示派生色怎么算，落地时把它们写进 custom.css / twikoo.css / archive-page.css 里对应模块的选择器中。

需要注意三件事：

  1. 文字对比度：主题色只用于图标、边框、强调数字。正文和标题不要直接用满饱和的主题色，压深或用主题自带的 --font-color。
  2. 暗色模式：[data-theme="dark"] 下要把压深色换成提亮色（主题色混白），否则深底上会看不清。
  3. color-mix 兼容性：现代浏览器都支持；如果站点要兼容很老的浏览器，给每个变量先写一个普通色值兜底，再写 color-mix 覆盖。

新模块挂进来之前，先检查它有没有写死颜色。比如归档卡片的背景用的是 color-mix(in srgb, var(--card-bg) 76%, transparent)，所以美化面板调整卡片透明度时，归档卡片会一起变；如果写成 #fff，就永远是白色。

改完怎么验证与部署

十节的改动分别落在 source/link/、source/about/ 两个页面，source/css/ 下的 custom.css、twikoo.css、archive-page.css，source/js/ 下的几个脚本，以及 _config.yml / _config.butterfly.yml。按下面五步走一遍再上传：

  1. 生成：在博客根目录执行 hexo generate（也可以 npm run build）。最后一行是 Generated 才算通过；改过 scripts/ 下的构建脚本必须重新生成，否则构建期过滤器不生效。
  2. 本地预览：执行 hexo server，打开 http://localhost:4000。重点看 /link/ 的三个格式标签页与两个复制按钮、/about/ 的名片卡与线路检测面板、/archives/ 的年份网格与吸顶、文章页评论区配色。
  3. 强制刷新或清缓存：Ctrl + F5 硬刷新；如果开过 Service Worker，再到 F12 → Application → Service Workers 点 Update 或 Unregister，否则 custom.css、twikoo.css、archive-page.css 仍是缓存里的旧文件。改过 CSS 记得同步升 _config.butterfly.yml 里的 ?v= 版本号。
  4. F12 检查 404：Console 不能有 404 或 Uncaught；Network 里确认 link-apply.js、about-page.js、archive-page.js、atom.xml 都是 200。打开 /atom.xml 能显示且是合法 XML，说明订阅源和 BOM 都正常。
  5. 部署：把 public/ 按原来的托管方式上线——Nginx 覆盖站点根目录、GitHub Pages 推 gh-pages 分支、Vercel 重新部署，或 hexo deploy（_config.yml 里配了 deploy 才可用）。上线后关掉浏览器缓存再访问一次，确认线上和本地一致。
